# UI·사용 흐름 검증 · 2026-09-16

이번 점검은 버튼의 크기뿐 아니라 기능별 묶음, 여백, 좁은 화면의 정보 순서를 대상으로 했다.

## 개선

- 지도 보기 선택을 하나의 묶음으로 정리하고 전투 확대 설정을 분리했다.
- 모험·상점·도감을 한 줄의 도구 묶음으로 정리했다. 좁은 화면에서 도감만 아래로 내려가던 배치를 없앴다.
- 지도 확대·축소, 크기 맞춤, 손동작, 동작 줄이기의 간격과 경계를 정리했다.
- 작업 필터·프로젝트 선택·세션 상세의 주요 동작과 닫기 위치를 정돈했다.
- 상점 분류는 넓은 화면에서 가로 묶음, 좁은 화면에서 3×3 배열로 보여준다.
- 작은 상점에서는 장비·능력치·자동 구매를 기본 접힘으로 두어 상품을 먼저 볼 수 있게 했다. 펼치면 기존 설정을 그대로 사용할 수 있다.
- 상품 카드는 해당 장비만 미리 보여주고, 현재 전체 착용 모습은 캐릭터 정보에 유지한다.

## 검증 방법과 범위

격리된 Chrome에서 클릭·구매·해제·저장·키보드 선택·정렬을 검사했다. 실제 사용자 데이터와 분리된 테스트 지갑을 사용했다.

추가로 `/Applications/AgentTown.app` 설치본을 실제로 실행하고 Electron 화면에 연결했다. 390·960·1440px 각각에서 지도, 세션 상세, 상점, 도감을 직접 열고 화면을 캡처해 검토했다. 실제 세션을 선택하고 상점 분류 전환, 작은 화면의 장비 설정 펼치기·접기, 도감·상세 닫기를 검사했다. 실제 별가루는 구매 테스트에 사용하지 않았다. 테스트 중 바꾼 전투 확대 설정은 원래 값으로 복원했다.

- 360~1440px에서 상단 버튼 배치와 글자 잘림 검사
- 390·960·1440px에서 9개 상점 분류의 가격순 정렬·구매 가격 표시·키보드 선택 유지
- 390~960px의 7개 너비에서 상점·버튼·닫기 동작 회귀 검사
- 일반·보조 세션 선택, 해당 캐릭터의 상점 연결, 지도 찾기 회귀 검사
- 확대 전투 켜기·끄기와 설정 저장, 전투 계속 진행 검사
- 모험·주민 대결·공동 토벌 로직 검사

이번 UI 수정본을 Windows 실기기에서 다시 조작한 것은 아니다. Windows 배포 ZIP은 새 코드로 다시 생성했다.
