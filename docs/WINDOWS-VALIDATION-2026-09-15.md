# AgentTown Windows 검증 · 2026-09-15

## 실행 환경

Windows 11 Pro x64의 실제 바탕화면 사용자 세션에서 ZIP 설치 프로그램을 실행했다.
WSL은 사용하지 않았다. 동봉 Electron 43.4.0 / Chrome 150과 Python 3.12.10으로
실행했으며, SSH로 연결한 Playwright가 Windows Electron 화면을 직접 조작했다.

## 설치와 데이터 보존

- 이전 버전 앱이 실행 중일 때 설치가 종료 코드 1로 중단되고 종료 안내를 표시했다.
- 기존 앱을 정상 종료한 뒤 사용자 데이터 폴더를 별도 백업했다.
- `설치.cmd`가 AgentTown을 현재 사용자 Programs 폴더에 설치했다.
- 바탕화면과 시작 메뉴의 AgentTown 바로가기가 새 AgentTown.exe를 가리켰다.
- 새 앱의 창 제목과 알림 제목이 AgentTown으로 표시됐다.
- 이전 앱과 새 앱에서 동일한 검증용 주소를 열어 저장 값 2개와 추가한 검증 표식이 유지됨을 확인했다.
  이 표식은 실제 사용자의 구매 내역이 아니다. 별도로 실제 상점에서 구매한 장비·잔액의 화면 재로드 후 유지도 검사했다.
- 원래 프로필 저장 값을 복원하고 테스트 아이템과 표식을 제거했다. 기존 설치와 데이터 백업은 삭제하지 않았다.

Electron의 외부 연결 기능은 읽기 전용으로 노출된다. 일반 브라우저용 테스트의 가짜 연결 함수 대입은
이 환경에서 동작하지 않아 처음 더블클릭 검사가 실패했다. 실제 앱의 프로세스 간 메시지 수신부를
검증 중에만 계측한 뒤 복구했으며, 더블클릭 1회가 연결 요청 1회를 보내는 것을 확인했다.
실제 Codex 화면이 열렸다는 뜻은 아니다.

## 추가 로컬 회귀 검사

- 세션 서버 15개, 네이티브 알림 3개, 모험·주민전·공동 토벌 로직 검사 통과.
- 화면 배율 1·2에서 스킬 위치 288개 검사 통과.
- 커진 다섯 속성 효과를 주민전·몬스터전의 200개 프레임에서 비교해 화면/전투 틀 잘림 없음 확인.
- Mac 설치본 소스 일치와 앱 재실행 확인.

## 확인하지 못한 항목

이 Windows PC에는 로그인된 Codex 실행 파일과 실제 작업 기록이 없다.
따라서 실제 계정 사용 한도 조회와 `codex://`를 통한 실사용 작업 열기는 미검증이다.
세션 검사는 격리된 테스트 기록을 사용했다. Windows 알림은 OS 표시 이벤트와 무음 설정을
확인했으며, 배너 자체 화면 촬영이나 소리 녹음으로 검증하지 않았다.
NSIS EXE 설치 파일은 이번 ZIP 설치 검증 범위에 포함하지 않았다.
