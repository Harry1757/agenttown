# README 화면 캡처

2026-09-16, 최신 AgentTown 코드를 격리된 로컬 Chrome에서 실행해 최신 UI와 확대 전투 화면을 촬영했습니다.

- 실제 Canvas 렌더러와 상점·도감 화면을 사용했습니다. 별도의 콘셉트 이미지나 합성 UI가 아닙니다.
- 격리된 브라우저에서 세션 이벤트와 `/api/usage` 응답을 데모로 대체했습니다. 실제 세션이나 계정 정보는 포함하지 않습니다.
- 세션 이름, 토큰, 지갑, 장비, 도감 기록은 공개용 예시입니다. 전투는 앱의 전투 함수를 사용하고 시간을 고정해 해당 장면을 캡처했습니다.
- 기본 화면은 1440×900이며, 전투 이미지는 같은 화면의 지도 영역을 캡처했습니다. `town-compact.png`는 960×580, `equipment-compact.png`는 390×700입니다.
- 게임 본체와 사용자의 저장 데이터는 변경하지 않았습니다.

| 이미지 | 내용 |
| --- | --- |
| `town.png` | 마을과 작업 목록 |
| `session.png` | 세션 선택 및 상세 정보 |
| `equipment.png` | 세션별 지갑·장착 상태·구매 목록 |
| `legendary.png` | 주민 대전의 전설검 참격 |
| `skill-*.png` | 화염·번개·물·바람·안개 일격 |
| `raid.png` | 몸 크기를 유지하며 흩어 선 6명의 공동 토벌 |
| `journal.png` | 보스 발견·승패·마을 사건 기록 |
| `duel-arena.png` | 확대 전환을 확인한 뒤 촬영한 세션 대전과 피해 반응 |
| `monster-battle.png` | 양측 체력이 남아 있는 실제 몬스터 보스전의 공격 장면 |
| `town-compact.png` | 작은 창의 버튼 배치와 하단 사용량 |
| `equipment-compact.png` | 접힌 장비 설정과 3×3 분류 버튼 |

세션 대전·몬스터전 이미지는 확대 전투가 활성화된 상태에서 실제 전투장 크기를 계산해 캡처했습니다. 마을 전체를 작게 담거나 전투 화면이 열리기 전에 촬영하지 않습니다.

확대 대전 2장은 2배 화면 배율로 촬영했습니다. 재촬영 함수는 `tools/browser-readme-battles.js`이며, 독립된 Playwright 브라우저 컨텍스트에서 사용합니다.
