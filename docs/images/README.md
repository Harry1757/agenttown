# README 화면 캡처

2026-09-15, 앱 코드 `547f336`을 로컬 Chrome에서 실행해 촬영했습니다.

- 실제 Canvas 렌더러와 상점·도감 화면을 사용했습니다. 별도의 콘셉트 이미지나 합성 UI가 아닙니다.
- 격리된 브라우저에서 `/events`와 `/api/usage` 응답을 데모로 대체했습니다. 실제 세션이나 계정 정보는 포함하지 않습니다.
- 세션 이름, 토큰, 지갑, 장비, 도감 기록은 공개용 예시입니다. 전투는 앱의 전투 함수를 사용하고 시간을 고정해 해당 장면을 캡처했습니다.
- 원본 화면은 1440×900입니다. 전투 이미지는 같은 화면에서 전투 영역을 1050×600으로 잘라 촬영했습니다.
- 게임 본체와 사용자의 저장 데이터는 변경하지 않았습니다.

| 이미지 | 내용 |
| --- | --- |

| `session.png` | 세션 선택 및 상세 정보 |

| `journal.png` | 보스 발견·승패·마을 사건 기록 |
