## 작업이 모이는 작은 마을

터미널과 작업 목록을 번갈아 보는 대신, 각 세션이 지금 무엇을 하는지 마을에서 살펴보세요. 도구 사용에 따라 방을 옮기고, 답변을 기다리는 주민은 라운지에 모입니다.

| 일하는 모습을 한눈에 | 필요할 때 바로 이어서 |
| --- | --- |
| 세션마다 하나의 캐릭터, 토큰 사용량에 따라 달라지는 몸집 | 한 번 클릭하면 작업 제목·모델·최근 도구·토큰 확인 |
| 가까운 방은 문과 복도를 따라 걷고, 먼 방은 포탈로 이동 | 더블클릭하면 해당 Codex 작업 열기¹ |
| 작업 중·내 응답 필요·완료 상태와 계정 한도 표시 | 검색, 프로젝트 필터, 즐겨찾기, 지도에서 찾기 |
| 작은 창에서는 작업 목록과 하단 사용량을 간결하게 표시 | 응답 요청·답변 완료를 **소리 없는 배너**로 알림¹ |

## 확대 화면으로 보는 전투

전투는 **세션끼리 대결**, **몬스터 사냥**, **여러 세션이 함께하는 공동 토벌**로 나뉩니다. 체력·공격력·방어력·치명타·착용 장비가 실제 승패에 반영됩니다.

### 세션 대전 · 별빛 결투장

![확대된 별빛 결투장에서 두 세션이 검을 맞대고 피해를 주고받는 장면](docs/images/duel-arena.png)

두 세션이 가까이 마주치면 별빛 결투장에서 겨룹니다. 각자의 체력과 몸집을 유지하고, 공격하는 쪽은 앞으로 숙여 검을 휘두르며 맞은 쪽만 밀려납니다. 승리하면 상대 등급에 따른 별가루와 승리 기록을 얻습니다. 같은 두 세션이 같은 방에 계속 머무는 동안에는 반복해서 대결하지 않습니다.

### 몬스터 사냥 · 던전 전투

![확대된 던전 전투에서 세션 캐릭터가 10단계 몬스터 보스를 공격하는 장면](docs/images/monster-battle.png)

방 안을 돌아다니는 몬스터와 마주치면 사냥이 시작됩니다. **1~10단계 몬스터와 보스, 12·14·16단계 상위 보스**가 있으며, 강한 적일수록 별가루 보상도 큽니다. 몬스터도 직접 다가와 공격하고, 작은 세션은 패배할 수 있습니다.

- **피해에 맞는 반응** — 작은 피해는 가볍게 움찔하고, 큰 피해는 더 크게 밀리고 기울어집니다.
- **스킬과 마지막 일격** — 기를 모은 뒤 이동해 공격합니다. 전투 중에도 확률적으로 기술을 사용하고, 보스는 고유 필살기를 씁니다.
- **길어지면 빠르게** — 전투가 10초를 넘으면 전체 흐름이 1.3배속으로 진행됩니다.
- **원할 때만 확대** — 상단의 전투 확대 설정을 끄면 마을을 보면서 전투와 보상은 계속 진행됩니다. 전투가 끝나면 미뤄 둔 방 이동을 이어갑니다.

### 작은 주민의 대역전, 전설의 검

![몸집보다 큰 전설검으로 공격하는 실제 주민 대전](docs/images/legendary.png)

작은 몸집에서 터져 나오는 커다란 한 방. 긴 기 모으기와 빛나는 검, 초승달 참격으로 전세를 뒤집습니다. **베기 → 상대 쓰러짐 → 검이 부드럽게 줄어듦 → 전투 종료**까지 이어집니다.

작은 쪽이 전설검 후보일 때, 누적 토큰 **10M 이하에서는 40%, 그보다 많으면 20%** 확률로 발동합니다. 몬스터에게 연속으로 패배한 주민을 위한 전설검 구제 장치도 있습니다.

## 내 세션만의 장비와 작은 동행

![세션을 선택해 장비를 구매하고 장착하는 상점의 실제 화면](docs/images/equipment.png)

별가루를 모아 **56종의 아이템** 중에서 골라 보세요. 무기·방패·머리·몸·장갑·신발·장식·펫까지, 세션마다 독립된 지갑과 장비를 가집니다.

- 전체·부위별 목록을 **낮은 가격순**으로 정렬합니다. 상품 카드에는 해당 장비만 미리 보여주고, 현재 착용 모습은 별도로 확인할 수 있습니다.
- 구매한 장비의 공격력·방어력·체력 등 능력치가 전투에 반영됩니다.
- 화려한 상위 무기, 날개와 장식, 곁을 따라다니는 작은 용과 불사조를 장착할 수 있습니다.
- 무기는 전투할 때 등장하고, 액세서리와 펫은 마을에서도 함께합니다.
- 공격·방어 중심 등 자동 장비 선택을 세션별로 설정할 수 있습니다.

## 혼자서는 버거운 보스도, 함께라면

![마을 중앙에 등장한 공동 토벌 보스와 여섯 명의 주민](docs/images/raid.png)

중앙에 균열이 열리면 **휴게실을 제외한 참여 가능한 주민들**이 모여 보스에 맞섭니다. 주민은 토큰에 따른 몸집 차이를 유지한 채 흩어 서며, 배치는 전투마다 달라집니다. 보스는 한 명을 연속으로 공격하거나 여러 주민을 공격할 수 있습니다. 낮은 등급의 참가자는 승리 시 성장 보너스를 받아 다음 장비에 더 빨리 다가갑니다.

모험 중 만나는 희귀 보물 몬스터, 함께 싸운 친구와 라이벌, 발견한 보스의 기록은 **모험 도감**에 남습니다. 세션이 마을을 떠나도 그 기억은 유지됩니다.

## 시작하기

**기본 데스크톱 앱은 Codex의 로컬 작업 기록이 있는 PC**에서 사용합니다. Claude Code 기록용 모듈도 포함되어 있으며, 별도 실행 방법은 아래 안내를 참고하세요. 일반 ChatGPT 웹 대화를 읽는 앱은 아닙니다.

| 환경 | 실행 방법 |
| --- | --- |
| macOS 앱 | 전달받거나 직접 빌드한 `AgentTown.app` 실행. 창을 닫으면 메뉴 막대에 남습니다. |
| Windows ZIP | `AgentTown-Windows-x64.zip` 전체 압축 해제 → `설치.cmd` 실행. Python·Node.js 별도 설치 없이 사용합니다. |
| 소스에서 실행 | Python 3.12 환경에서 저장소 루트의 `./launch.sh` 실행 → `http://127.0.0.1:8766` 접속. |

**설치 파일은 소스 저장소에 포함되어 있지 않습니다.** 패키지 생성, Windows EXE 빌드, 환경 변수와 플랫폼별 검증 범위는 [설치·실행 안내](docs/INSTALL.md)에 정리했습니다.

```sh
git clone https://github.com/Harry1757/agenttown.git
cd agenttown
CODEXTOWN_PYTHON=python3.12 ./launch.sh
```

### Claude Code로 실행하기

Claude Code의 로컬 기록은 별도 진입점으로 읽을 수 있습니다.

```sh
python3.12 agenttown.py --provider claude
```

기본 접속 주소는 `http://127.0.0.1:8765`입니다. 현재 데스크톱 앱의 기본 서버와 계정 한도 조회·작업 바로 열기는 Codex용입니다. 두 제공자의 기록을 한 목록으로 합치는 기능은 아직 제공하지 않습니다.

### 이전 버전에서 업데이트하기

앱 이름을 AgentTown으로 바꿨습니다. 기존 장비·별가루·도감·알림 설정을 이어 쓰도록 저장 폴더와 내부 식별자는 유지합니다. 기존 환경 변수도 계속 사용할 수 있습니다. 자세한 호환 설정은 [실행 안내](docs/INSTALL.md#환경-변수)를 참고하세요.

### 내 작업 기록은 어디로 가나요?

세션은 기본적으로 `~/.codex`의 로컬 기록을 읽습니다. 서버는 `127.0.0.1`에만 열리고, 코드 본문·도구 결과·인증 토큰을 화면에 보내지 않습니다. 계정 한도는 로그인된 Codex의 App Server로 조회하며, 새 모델 작업을 실행하지 않습니다.

장비·별가루·도감·즐겨찾기는 로컬에 저장됩니다. 게임 연출은 실제 Codex 작업을 실행하거나 모델 성능을 높이지 않습니다. 토큰 표시 역시 청구 금액을 계산하는 지표는 아닙니다. 수집 범위와 상태 추정의 한계는 [데이터와 한계](docs/INSTALL.md#데이터와-한계)를 확인해 주세요.

## 핵심 설계와 검증

| 구성 | 역할 |
| --- | --- |
| Python 수집기 | Codex·Claude Code의 로컬 기록을 읽어 화면에 필요한 세션 상태로 정리합니다. 제공자는 실행 시 선택합니다. |
| 이벤트 전송(SSE) | 로컬 HTTP 서버가 세션 변화를 브라우저로 전달합니다. |
| Canvas 2D | 마을 이동, 전투, 장비와 효과를 그립니다. 게임 진행과 실제 AI 실행은 별개입니다. |
| Electron | 창·메뉴 막대·운영체제 알림과 작업 바로 열기를 연결합니다. |

소스 실행과 아래 검증은 **Python 3.12 · Node.js 22**를 기준으로 합니다. macOS 기본 Python 3.9에서는 시간 측정 방식 차이로 Codex 기록 검사 일부가 실패하므로 Python 3.12를 선택하세요. Python 수집기는 표준 라이브러리를 사용하며, 데스크톱 의존성은 `app/package-lock.json`으로 고정합니다.

```sh
# 저장소 루트: 로컬 기록 해석과 마을 동작 검증
python3.12 -m unittest test_codextown -v
python3.12 test_claudetown.py
node test_town_scale.js
node test_wander.js
node test_travel.js
node --test app/test-server-command.js app/test-notifications.js

# 데스크톱 개발 실행
npm --prefix app ci
npm --prefix app start
```

macOS와 Windows용 패키지 구성이 있습니다. Windows 설치 파일은 Windows에서 빌드합니다. 위 명령은 소스 검증용이며 실제 AI 응답 실행이나 모든 운영체제의 설치 성공을 보증하지 않습니다. 날짜별 확인 범위는 [Windows 검증 기록](docs/WINDOWS-VALIDATION-2026-09-15.md)과 [실행 안내](docs/INSTALL.md)를 참고하세요.

## 만드는 데 사용한 것들

**Python**으로 세션 기록을 읽고, **Server-Sent Events(SSE)**로 상태를 전달합니다. 마을과 전투는 **Canvas 2D와 JavaScript**, 데스크톱 앱은 **Electron**으로 구성되어 있습니다.

AgentTown은 AI 세션을 살펴보는 도트 작업실에 작은 던전 모험을 더한 앱입니다. 픽셀 아트는 **Kenney**의 Tiny Town, Tiny Dungeon, Roguelike Indoor, Roguelike Characters 에셋을 사용합니다. 에셋 라이선스는 CC0이며, 원문은 [마을·던전 에셋](assets/LICENSE.txt)과 [캐릭터·장비 에셋](assets/LICENSE-equipment.txt)에 보존되어 있습니다.
